3. pth 檔通常是 PyTorch 的模型權重檔(在 AI 領域)，本質是二進為檔案，所以必須要透過像是
   [netron.app](https://netron.app/) 這種開源模型檢視器才能打開。打開後直接找 flag
   ，但是並有任何線索，都是模型的參數，所以問題不是出在檔案本身

4. 網頁上的內容基本上都查詢完了，但是還有個疑問：上傳 model 的 api 沒有找到，所以進行
   code audit ，從剛剛的<Color c="blue-3">註冊 / 登入</Color>看到<Color c="blue-3">下載
   model / 上傳 model</Color>
   - 從 `auth.py` (註冊 / 登入)開始看，針對 username 有做 `r'[^a-zA-Z0-9_\-]'`
     的過濾，確認 username 裡面沒有除了 `a-z`, `A-Z`, `0-9`, `_`, `-`
     以外的符號，基本上就不存在使用 path traversal 的空間(不能使用 `/`)

5. 緊接著檢查控制 model 下載 / 上傳的 `models.py` ，在 `action == 'download'` 就能看到 `.pth`
   檔的來源，仔細觀察 `action == 'upload'` 會發現，根本沒有針對權限的檢查。馬上去檢查前端，在
   `app.js` 中可以看到， `user.privilege` $\geq$ `2` 才會顯示 upload 的 button

   call api 理論上就能夠繞過前端的權限檢查，直接上傳檔案了

6. 在知道能夠上傳檔案之後，還是要繼續看 source code ，在 `action == 'change_owner'`
   這裡，能夠看到 `re.search(r'[^a-zA-Z0-9_\-/]', new_owner)` ，代表 new_owner
   這個參數允許 `/` ，有可能可以做 path traversal ，而後面的語法又用到了 `shutil.move`
   ，會把檔案從舊的 owner 的資料夾移動到新的 owner 的資料夾

   {/* prettier-ignore */}
   <AlertBlockquote type="info" title="shutil 相關">
     全名 shell utilites (shell 實用工具，類似 python 內的檔案總管)\
     `shutil.move(A, B)` ：其中 `A` 是舊的檔案路徑， `B` 是新的檔案路徑。把檔案從
     `A` 路徑剪下並貼上到 `B` 路徑
   </AlertBlockquote>

   ```py
   elif action == 'change_owner':
       if not token or (user:= get_session_user(token)) is None:
           print()
           print(json.dumps({'ok': False, 'error': 'not authenticated'}))

       model_id = qs.get('id', [''])[0]
       new_owner = qs.get('new_owner', [''])[0]
       if not model_id or not model_id.isdigit() or not new_owner or re.search(r'[^a-zA-Z0-9_\-/]', new_owner):
           print()
           print(json.dumps({'ok': False, 'error': 'bad parameters'}))
           exit(0)
       model = get_model(int(model_id))
       if not model:

       elif model['owner_id'] != user['uid']:
           print()
           print(json.dumps({'ok': False, 'error': 'this is not your model'}))
       else:
           success, msg = change_model_owner(int(model_id), new_owner)
   ```

   - 經過 `curl -s -H "Cookie: session=$SESS" "$HOST/cgi-bin/users.py?action=getmyinfo"`
     可以拿到自己的 uid ，接著再把針對 `users.py` 的 query string 改成 `?action=list&owner=2`
     就能拿到自己上傳模型的 `id` 以及 `filename` ，用於驗證可以任意搬檔
